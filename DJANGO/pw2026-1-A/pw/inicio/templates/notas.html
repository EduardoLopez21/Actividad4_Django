Diferencias entre Programación del Lado del Cliente y Lado del Servidor

Lado del Cliente (Frontend)

  • Entorno de ejecución: El navegador web del usuario.
  • Tecnologías principales: HTML, CSS, JavaScript (React, Vue, etc.).
  • Responsabilidad: Interfaz de usuario, diseño, animaciones, interacción directa con el usuario, y validaciones iniciales.
  • Seguridad: Código visible y manipulable por el usuario. No apto para procesar información sensible o lógica de negocio crítica.

Lado del Servidor (Backend)

  • Entorno de ejecución: Un servidor remoto (o local en desarrollo).
  • Tecnologías principales: Python (Django), Java (JSP/Spring), PHP, Node.js, Ruby, etc.
  • Responsabilidad: Lógica de negocio pesada, autenticación, seguridad, comunicación con bases de datos.
  • Seguridad: El código está oculto para el usuario, es un entorno seguro para procesar contraseñas y datos privados.

Diferencias entre Almacenamiento Local y Orígenes de Datos (Bases de Datos)

Almacenamiento Local / Sesiones Temporales

  • Dónde reside: Memoria RAM del servidor, archivos temporales, o en el navegador del usuario (LocalStorage, Cookies).
  • Persistencia: Volátil. Si el servidor se reinicia o la sesión caduca, los datos se pueden perder (como pasaba antes de migrar esta app).
  • Capacidad: Muy limitada (generalmente unos pocos megabytes en navegadores o limitada por la RAM del servidor).
  • Uso común: Carritos de compras temporales, tokens de sesión, preferencias de la interfaz (modo oscuro).

Orígenes de Datos (Bases de Datos Ej. PostgreSQL)

  • Dónde reside: Servidores especializados de bases de datos, con almacenamiento en disco persistente.
  • Persistencia: Permanente. Los datos sobreviven a reinicios del servidor y cortes de energía.
  • Capacidad: Escalable a terabytes o petabytes.
  • Uso común: Almacenar información de usuarios, historial médico, catálogo de productos, o en este caso, nuestros "servicios" creados.
